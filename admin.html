Sign in

Only the club admin can add matches. Sign in with the admin key, a GitHub token that can only start this site's update job.


How do I get an admin key?
  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → ombhilare999/cricket.
  3. Permissions → Repository: Actions: Read and write, Contents: Read-only. Nothing else.
  4. Generate the token, copy it, and paste it above.
