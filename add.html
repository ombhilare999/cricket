Submit a scorecard

Anyone in the club can add a match. Paste the full scorecard link from CricClubs.

This opens a pre-filled GitHub issue, so you need a free GitHub account. Press Create there. A bot checks the match, adds it, and replies on the issue within a couple of minutes.

Rules

A match is added only if all of these hold:

  • The link is a CricClubs fullScorecard.do link from our tournaments.
  • The scorecard shows our team with its exact name: True Blue Falcons.
  • Every one of our players on the scorecard matches a roster name exactly. Capitalisation and (c)/(wk) markers don't matter, but initials and nicknames are not accepted.
  • The match hasn't been added before. Each match is added once.
